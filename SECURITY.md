# Security policy

This tool is intended for authorized assessment and local use only. Do not expose the unauthenticated development server to untrusted networks.

Please report security issues in the application privately to the repository maintainer before public disclosure. Do not include real secrets, customer data, or unredacted assessment evidence in an issue.

The current release is an MVP and is not independently audited. It is not a replacement for a professional security assessment, and scanner observations require human review.
