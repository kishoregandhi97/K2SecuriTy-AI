Configure AI locally

Edit .env in the project directory. For Ollama, start the Ollama service, pull a model, then set AI_ENABLED=true, AI_BASE_URL=http://127.0.0.1:11434/v1, and AI_MODEL to the model you installed. Hosted providers must support the OpenAI-compatible Chat Completions API used by this app.

Never commit .env or paste API keys into the browser. Restart Uvicorn after configuration changes.
